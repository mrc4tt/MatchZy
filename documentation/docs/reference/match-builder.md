# Match config builder

Fill in the form, then copy or download `match.json`. Nothing leaves your browser.

??? note "How it works"
    1. **Fill in** the match, the maps and the two teams. The config on the right updates as you type, and the problems the plugin would warn about when loading show above it.
    2. **Copy** or **Download** the config.
    3. **Load it** on the server: from your panel with `matchzy_loadmatch_url`, or put it in `csgo/cfg/MatchZy/` and run `matchzy_loadmatch cfg/MatchZy/match.json`.

    **Import** loads an existing match config so you can change it. The form is kept in this browser until you press **Reset**. Every field is explained in [Match config JSON](match-config.md), and there are ready-made [examples](match-examples.md).
