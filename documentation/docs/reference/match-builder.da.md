# Match config-builder

Udfyld formularen, og kopiér match configen, eller download den som `match.json`. Load den med `matchzy_loadmatch_url` fra jeres panel, eller læg den i `csgo/cfg/MatchZy/`, og brug `matchzy_loadmatch`. Alle felter er forklaret i [Match config JSON](match-config.md). **Importér** indlæser en eksisterende match config, så du kan redigere den. De problemer, plugin'et ville advare om ved load (en spiller på begge hold eller også som spectator, en roster større end holdstørrelsen), vises over resultatet. Din formular gemmes i denne browser. Intet forlader din browser.
