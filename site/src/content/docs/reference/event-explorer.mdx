Every event MatchZy can send to `matchzy_remote_log_url`, with its fields and an example payload. The list is read from the plugin's source when the site is built, so it always matches this version. How to set up the endpoint is in the [Live events API](/guides/events/) guide, and what each event means and when it is sent is in [Events](/reference/events/).

`matchzy_events_format` picks the format of the live scorebot events: **Get5** (default) or **legacy**. Match flow and server events are the same in both.
